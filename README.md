# Examples for Embecosm Application Note 16

These are the example models used in the appendix of Embecosm Application
Note 16.  See the Embecosm [application note download
page](https://embecosm.com/downloads/application-notes/) to obtain the most
recent version.

## The models

We provide three models.

- a simple recognizer for 7-segment displays
- the same model, with some text debug output
- the same model, with some graphical debug output.

All details of how to use these models are in the application note.
